# Held Together (menu)

**For:** the main menu, lobby, locker and shipyard (every screen in `#lobby`).
**Mood:** the crew's home between jobs, and the score's home theme: the solo cello melody every mission piece shares in its colour. A used ship held together by duct tape, optimism and one very large cat: warm, a little scrappy, hopeful. It plays for as long as someone sits in a menu, so it must not build or end.

## Style of Music
```
warm intimate cinematic instrumental, the crew's home theme, 84 BPM, D major with a wistful minor turn, solo cello melody, felt piano, soft string pad, gentle sub pulse like the ship's heartbeat, soft brushed half-time drums, light struck metal pipe accents, faint ship hum, wide reverb, hopeful and a little scrappy, steady from start to end, no big build, loopable, ends on the same chord it starts on, no vocals
```

## Exclude Styles
```
vocals, choir, EDM, drops, epic trailer, aggressive, horror, bells, music box, lo-fi hip hop
```

## Lyrics (Instrumental off, tags only)
```
[Intro: soft ship hum, felt piano chords, gentle heartbeat pulse]
[Theme: solo cello melody]
[Verse: piano answers the cello, brushed half-time drums]
[Theme: cello melody again, strings under it]
[Bridge: piano alone, a wistful minor turn, light pipe accents]
[Theme: cello melody, a little fuller]
[Outro: back to the opening piano and hum, same chord as the start, no ending hit]
```

## Notes
- A loop, not a mission piece: 2:30-3:30 is plenty. Ask for no fade-out (it loops; the game can fade).
- Download the **stems** into `assets/music/Held Together/`.
