# Held Together (menu)

**For:** the main menu, lobby, locker and shipyard (every screen in `#lobby`).
**Mood:** the crew's home between jobs, and the score's home theme: the piano motif and cello melody the mission pieces echo. A used ship held together by duct tape, optimism and one very large cat: calm, a little mysterious, hopeful. It plays for as long as someone sits in a menu, so it must not build or end. (Rewritten 2026-11-07, like c1 and c2: the core of the liked songs, piano, orchestra, a wordless choir, good drums and a synth bass, with the old colour kept only as a hint.)

## Style of Music
```
mysterious warm cinematic instrumental, the crew's home theme, 84 BPM, D minor turning to D major, felt piano motif in wide reverb, solo cello melody, a soft distant wordless choir on ooh, warm analog synth bass pulse like the ship's heartbeat, soft half-time drums with a deep muted kick, light struck metal pipe accents, soft string pad, faint ship hum, hopeful and a little wistful, steady from start to end, no big build, loopable, ends on the same chord it starts on, no lyrics
```

## Exclude Styles
```
lyrics, sung words, lead vocals, rap, spoken word, EDM drops, dubstep, epic trailer, horror, bells, music box, lo-fi hip hop, aggressive
```
