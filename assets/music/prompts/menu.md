# Held Together (menu)

**For:** the main menu, lobby, locker and shipyard (every screen in `#lobby`).
**Mood:** the crew's home between jobs. A used ship held together by duct tape, optimism and one very large cat: warm, a
little scrappy, hopeful. It plays for as long as someone sits in a menu, so it must not build or end.

## Style of Music
```
warm lo-fi jazz instrumental, cozy spaceship hangar at night, 88 BPM, D major with a wistful minor turn, Rhodes electric piano chords, upright bass, brushed drums, muted trumpet melody, soft nylon guitar, vinyl warmth, relaxed and hopeful, steady groove from start to end, no big build, loopable, ends on the same chord it starts on, no vocals
```

## Exclude Styles
```
vocals, choir, EDM, drops, epic, orchestral, drone, bells, dark, aggressive
```

## Lyrics (Instrumental off, tags only)
```
[Intro: brushed drums and upright bass, Rhodes chords]
[Theme: muted trumpet melody]
[Verse: nylon guitar answers the trumpet]
[Theme: trumpet melody again, a little fuller]
[Bridge: Rhodes solo, bass walks]
[Theme: trumpet melody]
[Outro: back to the opening groove, same chord as the start, no ending hit]
```

## Notes
- A loop, not a mission piece: 2:30-3:30 is plenty. Ask for no fade-out (it loops; the game can fade).
- Download the **stems** into `assets/music/Held Together/`.
